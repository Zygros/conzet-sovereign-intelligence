# Contributing

**Always Add · Never Take · Zero Friction**

## Principles

1. Changes must be small, reviewable, and provenance-preserving.
2. Do not delete, archive, or rewrite history of any indexed repository.
3. Do not overwrite historical source material silently.
4. Keep credentials, generated runtime state, and private data out of commits.
5. Describe intent, affected paths, validation performed, and any unresolved uncertainty.

## Before opening a pull request

- Run any documented checks for the component you touch.
- Review `SECURITY.md` and this file.
- Prefer additive index updates over destructive merges.

## Status discipline

Claims remain **DESIGNED** until executable evidence is linked.
Local evidence does not equal independent reproduction.
