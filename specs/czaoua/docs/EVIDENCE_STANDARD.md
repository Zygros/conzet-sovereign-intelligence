# Evidence Standard

CZAOUA is an architecture/integration specification with experimental implementation material. Concepts such as infinite coherence, subjective time dilation, or portability must be treated as design claims unless current reproducible implementation evidence supports them.

## Status levels
- Implemented
- Tested
- Benchmarked
- Verified
- Designed
- Historical

## Verification gate
For each claimed capability, record the exact commit, implementation path, environment, command, output artifact, dependencies, and known limitations. Do not equate mathematical notation or architectural diagrams with empirical proof. Production/security claims require appropriate testing and review.
