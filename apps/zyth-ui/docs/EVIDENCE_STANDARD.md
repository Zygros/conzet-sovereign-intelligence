# Evidence Standard

This repository contains OmniNet/Phoenix architecture and implementation material. Architecture diagrams and provenance anchors do not establish runtime compatibility, production readiness, or security certification.

## Status levels
- Implemented
- Tested
- Benchmarked
- Verified
- Designed
- Historical

## Release gate
Claims must identify the exact commit and evidence artifact. Production claims require current tests, dependency/security review, deployment validation, and documented limitations. Custom cryptographic or routing constructions require qualified review before production use.
