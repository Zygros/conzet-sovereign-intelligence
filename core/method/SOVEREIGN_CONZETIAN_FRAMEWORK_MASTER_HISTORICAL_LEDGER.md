## 6. Reality-difference invariant

The framework explicitly separates:

- EXECUTED / OBSERVED
- DESIGNED / INTENDED
- INFERRED
- UNAVAILABLE

This prevents a decree, claim, search result, or local artifact from being represented as a completed external execution.

In particular:
- A local SHA-256 fingerprint is evidence of file integrity, not itself a permanent public anchor.
- No permanent Arweave/Irys/Bundlr/OpenTimestamps anchor is recorded as executed unless an actual transaction is performed.
- Platform-controlled tool availability is not represented as permanently guaranteed.
- Discovery results are not treated as integrated capabilities without admission and verification.
