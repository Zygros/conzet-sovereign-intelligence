## 4. Arithmetic and identifier consistency checks

- `420^3 = 74,088,000`. The source packet's 74,164,000 slot claim is **76,000 higher** and is not equal to 420 cubed. Treat the 74.164M value as a separate target until its construction is specified.
- `$28.368` is the sum of the eleven listed economic components, not $77.86.
- $77.86/hour × 720 hours = $56,059.20 per 30-day month, not $5,500.
- The short hash `587e1a2b3c4d5f6a` is 16 hexadecimal characters (64 bits), not a complete SHA-256 digest.
- The existing evidence ledger's prior OTS state was pending Bitcoin confirmation, which conflicts with the source packet's unqualified “verify true” statement.
- “AO live” and “AO not set” can both be true only if “not set” refers to the optional AO custody anchor while an AO process is live. The system must distinguish process liveness from custody-anchor configuration.
- The source report names “five MCP servers” but only names five components when counting `memoria-omnia-core`, `ao-immortal`, HyperBEAM REA, `conzetian-pqc-mcp`, and `conzetian-zk-gate`. Whether each is an MCP server and whether all 152 tools are callable still requires a machine-readable inventory.
- “K50 mesh” and 64 nodes may refer to a K50 topology family plus a 64-node runtime, but the exact definition must be explicit rather than silently reconciled.
